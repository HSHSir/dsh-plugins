# dsh-session-progress

在 DSH 会话表头加一条进度栏，显示当前回合的步骤、进展与用时。零依赖，两个文件。

## 它做了什么

| 半边 | 内容 |
| --- | --- |
| Host | 注册一段系统提示词：三步以上的任务先用 `todo_write` 写下 3–6 步，每完成一步立即更新。没有 `systemPrompt` 服务的宿主上，这一半不生效，客户端照常工作。 |
| Client | `conversation.session.header.actions` 里的进度胶囊 + `shell.overlay` 里的步骤浮层。 |

## 两种形态

- **模型写了计划**：分段条按清单画，上方是当前步骤名；点开按「正在做 / 待开始 / 已完成」分组。
- **没写计划**：把本回合的工具调用按意图折成阶段（查阅资料与代码 / 修改文件 / 执行命令 / 调度协作代理），显示最近几步和正在进行的那一步。永远不隐藏，空闲时显示「空闲」。

## 形状

胶囊是两行的，一行放文字、一行放条，所以比横排窄得多（208px）：

```
┌────────────────────────┐
│ 查阅资料与代码    ⏱ 3:38 │
│ ▬▬▬▬▬▬▬▬▬              │
└────────────────────────┘
```

条是满宽的：做完了的段是绿色，正在做的那段会呼吸，还没开始的段是暗色。没有清单时条是空的，但位置一直留着，所以表头不会因为状态变化而跳动。

## 用时

胶囊右端始终有一个 `m:ss` 计时，浮层右上角是同一条时间的 `用时 m:ss`：

- **回合进行中**：每秒走一次，从用户那条消息算起。
- **回合结束**：停在最后一个事件上，不再变化——这就是这一回合实际花掉的时间。

时间取自会话事件自带的时钟（Unix 毫秒），不额外发请求。

悬停提示里**不放正在走的秒数**：浏览器一旦发现 `title` 变了就会把原生提示收起来再显示，秒表在里面会变成每秒闪一次。回合结束后把「用时 3 分 41 秒」写进提示是安全的——这个值已经冻住了。

## 依赖

没有 npm 依赖。运行期只用宿主自带的 `todos` 投影、`useSession`、`useTrajectory` 与两个 slot；三者任一缺失时客户端降级显示，不报错。

## 安装

用插件市场「添加插件」选择本目录，或：

```js
plugin_manager install_bundle target: "<本目录绝对路径>"
```

装完在 **Plugins** 里确认 `session-progress` 这一行已启用。
